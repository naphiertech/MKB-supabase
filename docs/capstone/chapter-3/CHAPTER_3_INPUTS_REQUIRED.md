# Chapter III Inputs Required

## Purpose

This document converts every unresolved Chapter III confirmation marker into questions for the researchers. It does not answer the questions, revise Chapter III, select research methods, or make decisions on behalf of the researchers.

The current Chapter III contains **22** `[NEEDS CONFIRMATION: ...]` markers. Each marker is mapped below. Additional questions capture the four `[SOURCE REQUIRED]` markers, the citation gap for biometric/privacy concepts identified by the consistency audit, and the potential conflict between the repository title and the verified implementation.
